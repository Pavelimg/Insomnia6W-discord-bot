# Insomnia 6W Discord Bot

Discord-бот для игрового сообщества: управление участниками и внутренней экономикой, магазин ролей, справочные команды и мини-игра.

## Возможности

- автоматическая регистрация новых участников;
- просмотр баланса и переводы между пользователями;
- административное изменение баланса;
- магазин ролей и предметов;
- мини-игра с генерацией анимации;
- публикация правил, карты зон и информации о команде;
- получение случайных изображений через внешний API;
- хранение состояния в SQLite.

## Стек

Python, discord.py, asyncio, SQLite, Requests, Pillow, imageio.

## Запуск

Проект использует старую совместимую ветку `discord.py`, поэтому рекомендуется отдельное виртуальное окружение.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python main.py
```

В `.env` необходимо указать новый `DISCORD_BOT_TOKEN`. Рабочие токены нельзя хранить в исходном коде.

## Структура

- `main.py` — события Discord и команды;
- `non_db_func.py` — построение embed-сообщений;
- `Library.py` — генерация изображений и анимации;
- `data_text.py` — текстовые материалы;
- `config.py` — настройки и загрузка токена из окружения.

## Статус

Архивный учебный проект 2021 года. Он сохранён как пример событийной разработки, интеграции с внешним API и работы с SQLite; для запуска может потребоваться адаптация под актуальную версию Discord API.
